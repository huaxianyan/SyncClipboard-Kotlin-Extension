系统扩展从主体应用仓库独立出来，改为单独发版。扩展的代码与 `0.3.0` 相同，版本号递增到 `0.3.1`，此后与主体应用的版本号互不相干。

## 新功能

- 系统扩展独立成仓库，拥有自己的版本号与 Release，主体应用发版不再牵动扩展
- Obtainium 入口只跟踪本仓库的正式版本，不会再混选主体应用

## 改进

- 版本号去掉 `-ext` 后缀，直接使用 `0.3.1`
- 校验脚本与发布说明改为只覆盖系统扩展

详细设计见 [架构说明](https://github.com/huaxianyan/SyncClipboard-Kotlin-Extension/blob/v0.3.1/docs/architecture.md)，构建与发布见 [构建与发布](https://github.com/huaxianyan/SyncClipboard-Kotlin-Extension/blob/v0.3.1/docs/build.md)。
